Ashen Gate — tower defense
==========================

Snapshot of the Ashen Gate game: source, art, and app shell.

Play in the Grok preview, or with Node 22:
  npm install
  npm run dev

Controls
  Tap a tower, then grass beside the road to place it.
  Call waves from the bottom bar. Click a placed tower to upgrade or sell.
  Keys: 1/2/3 pick towers, Space starts the next wave or pauses, Esc cancels.

Towers
  Ballista   — cheap, fast bolts
  Mortar     — splash shells
  Rime Spire — slows the column
